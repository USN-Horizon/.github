# .github

This repository holds the public profile for the [USN Horizon](https://github.com/USN-Horizon) GitHub organisation.

| Path | What it is |
| --- | --- |
| `profile/README.md` | The organisation profile shown on [github.com/USN-Horizon](https://github.com/USN-Horizon) |
| `profile/assets/` | Logos used by the profile, one for light mode and one for dark mode |

## Editing the profile

Changes to `profile/README.md` go live on the organisation page as soon as they reach `main`. Check the preview before committing, and switch between light and dark mode to make sure the logo looks right in both.

Keep the content current. Update the current mission, flight history and sponsor list after each launch or sponsor change.
